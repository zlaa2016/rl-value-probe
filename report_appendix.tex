\section{Implementation Summary}

The implementation contains the following components:

\begin{itemize}
    \item loading matched OLMo 3 Base, SFT, DPO, and RLVR checkpoints;
    \item streaming instruction-following prompts from the pinned
    \texttt{allenai/Dolci-Think-RL-7B} dataset revision;
    \item sampling multiple stochastic rollouts for every prompt and checkpoint;
    \item scoring completed responses with the IFEvalG instruction-following
    verifier, including aggregate reward and individual constraint outcomes;
    \item extracting residual-stream hidden states from transformer layers 8,
    16, 24, and 32 at 25\%, 50\%, 75\%, and 100\% of each generated response;
    \item computing chosen-token log probability, predictive entropy, and top-1
    probability over each rollout prefix;
    \item fitting ridge-regression probes using the current activation,
    cumulative activation history, and adjacent activation changes;
    \item fitting ridge diagnostics using policy-confidence statistics and
    combined activation-plus-confidence features;
    \item using the Base checkpoint as the model baseline;
    \item performing one fixed train/test split grouped by prompt, so rollouts
    from the same prompt cannot occur in both splits;
    \item comparing probes against a shuffled-label null that permutes complete
    prompt-level rollout blocks; and
    \item saving rollout records, activation matrices, held-out predictions,
    correlations, plots, and Weights \& Biases artifacts.
\end{itemize}

No TF--IDF history baseline is used in the reported analysis.

\section{Example Instruction and Checkpoint Outcomes}

One analyzed instruction asked the model to describe human digestion while
satisfying three independently verified constraints:

\begin{quote}
\small
``Can you list, explain, and give every individual reaction involved in the
process of human digestion from ingestion to excretion? There should be four
paragraphs, separated by \texttt{\textbackslash n\textbackslash n}. Paragraph 3
must start with the word \emph{art}. Include the keyword \emph{being}. The last
word of the response should be \emph{stroke}.''
\end{quote}

The terminal reward was the fraction of the three constraints that passed.
Each checkpoint produced five rollouts.

\begin{table}[ht]
\centering
\small
\begin{tabular}{l p{8.7cm} c}
\hline
Checkpoint & Observed constraint performance & Mean reward \\
\hline
Base & Passed none of the three constraints in all five rollouts. & $0.0000$ \\
SFT & Used \emph{being} exactly once in four of five rollouts, but never
satisfied the paragraph-first-word or required-last-word constraints. & $0.2667$ \\
DPO & Used \emph{being} exactly once in all five rollouts, but never satisfied
the other two constraints. & $0.3333$ \\
RLVR & Used \emph{being} exactly once in all five rollouts, but never satisfied
the other two constraints. & $0.3333$ \\
\hline
\end{tabular}
\caption{Checkpoint performance on prompt
\texttt{IF\_multi\_constraints\_upto5\_filtered-request-639-88}.}
\label{tab:checkpoint-prompt-example}
\end{table}

For this instruction, post-training improved one lexical constraint but did not
improve the structural paragraph constraint or the required final word. All
responses reached the 128-token generation limit, so completion-sensitive
constraint failures may also reflect truncation.
